# Aurora Idol

Mobiles Neon-Slot mit Anime-Idols. Fünf Walzen, 20 Linien, Wild, Freispiele und eine Bühne, die auf Gewinne reagiert.

Nur **Spielgeld**. Keine Einzahlung, keine Auszahlung, kein Echtgeld-Glücksspiel.

Im Browser spielen — auf Android über „Zum Startbildschirm hinzufügen“ wie eine App. Die Vorschau läuft als Web-App; ein natives Play-Store-APK ist nicht Teil dieses Repos.

## Spielen

- **Bühne betreten**, dann **Drehen** (oder Leertaste).
- Einsatz ändern, **Auto** und **Turbo**.
- Drei **Zugabe**-Symbole starten Freispiele (Gewinne ×2).
- Luna ist Wild.
- Geht das Guthaben leer, holt **Zugabe** neues Spielgeld.

Stand wird lokal im Browser gemerkt.
